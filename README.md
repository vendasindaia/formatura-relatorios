# Relatórios de formatura

Páginas estáticas de relatório financeiro por turma, publicadas para envio direto aos responsáveis.

Cada relatório fica numa pasta de nome aleatório e a raiz não lista nenhum deles. As páginas trazem `noindex` e o `robots.txt` bloqueia buscadores — o endereço é o único controle de acesso, então **não divulgue em canal aberto**.

Os arquivos são gerados fora deste repositório (scripts que leem o CRM e a Vindi); aqui fica só o resultado.
